# ⭐ HyPerf 最简学习清单（只学能跑的部分）

## 1. **安装 + 启动项目**
你只需要会：

- `composer create-project hyperf/hyperf-skeleton`
- `php bin/hyperf.php start`

能跑就行。

---

## 2. **路由 + 控制器**
只学 3 个：

- GET 路由  
- POST 路由  
- 控制器返回 JSON  

示例：

```php
#[GetMapping(path: "/ping")]
public function ping() {
    return ["pong" => time()];
}
```

---

## 3. **依赖注入（DI 容器）**
HyPerf 的核心就是 DI。

你只需要会：

```php
public function __construct(UserService $service)
{
    $this->service = $service;
}
```

不需要学复杂的。

---

## 4. **协程机制（HyPerf 的灵魂）**
只学两个：

- `go(function(){})`  
- `parallel([...])`

示例：

```php
go(function () {
    sleep(1);
});
```

你只要知道：**HyPerf 所有 IO 都是协程自动调度**。

---

## 5. **中间件**
只学一个：

- JWT 校验中间件

示例：

```php
public function process(ServerRequestInterface $request, RequestHandlerInterface $handler)
{
    // 校验 token
    return $handler->handle($request);
}
```

---

## 6. **Crontab（定时任务）**
只学一个：

```php
#[Crontab(name: "demo", rule: "* * * * *", callback: "execute")]
public function execute() {
    // 定时任务逻辑
}
```

---

## 7. **Queue（队列）**
只学两个：

- Producer（生产者）
- Consumer（消费者）

示例：

```php
$producer->produce(new DemoMessage("hello"));
```

---

## 8. **Redis（缓存 + 队列）**
只学：

```php
$redis->set("key", "value");
$redis->get("key");
```

---

## 9. **数据库（Model + Query）**
只学：

```php
User::query()->where("id", 1)->first();
```

不需要 ORM 深度。

---

## 10. **写一个完整 CRUD（最重要）**
你只需要写：

- Controller  
- Service  
- Repository  
- Model  

这就是 HyPerf 的最小骨架。

---
